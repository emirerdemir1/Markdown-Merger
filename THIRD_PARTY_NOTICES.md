# Üçüncü Taraf Yazılım Bildirimi

Bu uygulama aşağıdaki açık kaynak kütüphaneleri kullanır. Hepsi ticari kullanıma
ve yeniden dağıtıma izin veren lisanslara sahiptir. Tam lisans metinleri
ilgili paketlerin kendi dizinlerinde bulunur.

| Kütüphane | Lisans | Kullanım amacı |
|---|---|---|
| markdown-it-py | MIT | Markdown ayrıştırma |
| mdurl | MIT | Bağlantı URL işleme |
| python-docx | MIT | Word (.docx) üretimi |
| openpyxl | MIT | Excel (.xlsx) üretimi |
| beautifulsoup4 | MIT | HTML ağacını okuma |
| soupsieve | MIT | CSS seçicileri |
| playwright | Apache-2.0 | PDF üretimi (Chromium / Edge) |
| pywebview | BSD-3-Clause | Masaüstü penceresi |
| lxml | BSD-3-Clause | HTML/XML işleme |
| bottle | MIT | pywebview yerel sunucusu |
| greenlet | MIT / PSF-2.0 | Playwright altyapısı |
| typing-extensions | PSF-2.0 | Python tip desteği |
| et-xmlfile | MIT | openpyxl bağımlılığı |
| proxy-tools | MIT | pywebview bağımlılığı |
| PyInstaller | GPL-2.0 + bootloader istisnası | `.exe` paketleme (dağıtım izinli) |
| pyobjc | MIT | macOS WebView desteği |

Bu uygulamanın kendisi MIT lisansı ile lisanslanmıştır (`LICENSE` dosyasına bakın).
